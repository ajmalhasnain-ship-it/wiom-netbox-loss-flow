End-to-end · every step

  
The four journeys, step by step.

  
A NetBox can leave the CSP's hands three ways — the CSP marks it lost, the system auto-marks it after the return window, or an agent collects it — and one way back: it's found and the money is refunded. Each step below is a real screen in the prototype, with the exact state it renders and what moves the CSP to the next.

Rule — recovery goes back where it came from
A deduction that hit the wallet is refunded to the wallet; a payout hold is released to the payout. The CSP is never left net-negative on a box that returns. This is why every loss screen carries the green reassurance line: “नेटबॉक्स लौटाने पर पूरे पैसे वापस हो जाएंगे।”

Per PRD — notify, with an unmissable fallback
Auto-loss is the one loss event the CSP didn’t initiate and money moves automatically, so the PRD requires the system to notify the CSP within C-11 (≤5s) and keep the charge visible in a “pending” state. The primary surface is a push notification → recovery breakdown. But a notification can be missed — so if it isn’t tapped, home falls through to a full-page blocker. The blocker is a takeover, not a scroll-past banner, so the PRD’s “charge visible to CSP” guarantee is never lost.

The app renders · the server drives

Charge · collect · reverse

  
The loss & recovery model.

  
A NetBox is Wiom hardware in the CSP’s custody. If it isn’t returned, its depreciated value is recovered from the CSP — never instantly, always over a stated window, and always reversible if the box comes back. Four principles govern every screen.


  
Rate card — depreciated recovery value

  
Recovery = base value × age-band factor. Never a flat penalty; an older box costs less.

  

    
Age bandFactorONT · ₹1,888 baseRouter · ₹1,062 base

    
      
0–12 months100%₹1,888₹1,062

      
12–24 months80%₹1,510₹850

      
24–36 months60%₹1,133₹637

      
36+ months20%₹378₹212

    
  


  
Four principles

  
1 · No instant deduction
Copy never says “₹X कट गए”. It says the money will be recovered over the next 30 days — a backend-decided window. This is why the confirm sheet reads “अगले 30 दिनों में आपके वॉलेट से ₹1,888 रिकवर की जाएगी”, not a past-tense deduction.

  
2 · Recovery goes back where it came from
If the box returns, the exact deduction is reversed to the exact place — wallet to wallet, payout to payout. The CSP is never left net-negative on a returned box. Every loss screen carries the green line “नेटबॉक्स लौटाने पर पूरे पैसे वापस हो जाएंगे।”

  
3 · Auto-loss notifies, self-loss confirms
When the system marks boxes lost (window lapsed), money moves without the CSP acting — so per PRD T1 the CSP is notified (push) within C-11 (≤5s) and the charge sits visible in a “pending” state until committed (C-12), then recovers over the cycle (C-13). When the CSP marks a box lost, a charge-warning sheet makes the ₹ explicit before they commit. Different initiator, different surface — never a scroll-past home banner for money that already moved.

  
4 · Agent pickup carries no upfront charge
Handing boxes to a Wiom agent is a return, not a loss — the pickup sheet shows “वापस करें” with no ₹ and no total. A charge only applies later, and only if a box isn’t actually produced.
